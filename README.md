# 砚藏安卓 TT 联动 0.2.8

适用于砚藏 Android 0.8.5 与采用同一联动协议的后续版本。首次在两端开启联动，在砚藏确认配对。配对后支持记住授权、自动重连。砚藏发送角色卡后，TT 自动接收。

## 安装

从本版本的 Releases 下载 `Yancang-TT-Android-0.2.8-install.zip`。在 TauriTavern 的扩展面板中打开「数据迁移」，选择「导入数据归档包」，导入 ZIP 后重新载入 TT。归档只包含 `data/default-user/extensions/yancang-tt/` 下的扩展文件。若扩展管理中出现两份砚藏联动，停用旧扩展。

[下载安卓 TT 联动扩展 0.2.8](https://github.com/yanxu-orange/ST-Orange-Yancang-TT-Bridge/releases/tag/v0.2.8)

砚藏 0.7.1 的连接码流程使用 0.2.6.2。PC 使用独立的配套扩展。
