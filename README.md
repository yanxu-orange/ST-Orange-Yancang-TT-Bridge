# 砚藏联动

在 TauriTavern 与砚藏之间发送、导入角色卡。

适用于 **TauriTavern 2.3.0** 和 **砚藏 Android 0.3.0 及以后版本**。

[下载砚藏](https://github.com/yanxu-orange/ST-Orange-Yancang/releases/latest)

## 1. 安装插件

在 TT 的扩展管理中，通过 Git 链接安装：

```text
https://github.com/yanxu-orange/ST-Orange-Yancang-TT-Bridge
```

安装后重载，打开 **砚藏联动**。

已有 Git 版可直接在扩展管理中更新。如果以前安装过 ZIP 版，请先停用或移除旧的砚藏联动，避免同时运行两份；不用删除角色卡。

## 2. 建立连接

使用前，请给 TT 和砚藏锁定后台，或使用小窗保持运行。可以参考平时防止 Termux 被杀后台的设置方式。

1. **砚藏**：在设置页、导入页或发送页发起连接，点击 **复制连接码 → 打开TT**。
2. **TT**：在砚藏联动中粘贴连接码，点击 **连接**。
3. 显示连接成功后，返回砚藏继续操作。

每次连接有效期为十分钟，剩余时间会显示在界面上。

## 3. 从 TT 导入角色卡

1. **砚藏**：选择 **导入 → TauriTavern**，完成连接后点击 **读取角色列表**；提示前往 TT 时打开 TT。
2. **TT**：等待列表就绪，返回砚藏。
3. **砚藏**：勾选角色卡，点击 **导入所选**，打开 TT。
4. **TT**：等待读取和传送完成，返回砚藏。
5. **砚藏**：等待导入预览，确认入库。

## 4. 发送角色卡到 TT

1. **砚藏**：打开角色卡详情，选择 **发送至酒馆 → TT**。
2. 建立连接后，点击 **发送角色卡**，打开 TT。
3. **TT**：在砚藏联动中点击 **确认接收为新角色**。

发送的是当前查看的版本和头像，在 TT 中新增角色，不覆盖已有角色。

## 5. 遇到问题

- 连接失败时，手动清理两边后台，再重新打开建立连接。
- 目前受测试环境限制，暂时无法保证每次连接都成功。
- 从 TT 导回的卡片有时仍会显示为不同版本，可在导入预览中查看并选择。
- 问题持续出现时，请分别在 **砚藏设置 → TauriTavern → 导出诊断** 和 **TT → 砚藏联动 → 导出诊断** 保存记录，反馈时附上两份文件。

诊断不包含角色正文或连接码，不会自动上传。**清除记录**只清除本端诊断，不会删除角色卡。
