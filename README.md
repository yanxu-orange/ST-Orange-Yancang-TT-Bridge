# 砚藏联动

供官方 TauriTavern **2.3.0** 与砚藏 Android **0.2.6**（正式诊断候选及以后），桥修订 **0.2.6.2** 同机使用的普通扩展。仅传输明确选择的角色卡，不调用模型、不自动同步整库，不修改TT。

## 首次安装

在TT“扩展”的Git安装入口粘贴完整仓库链接，安装后重载：

https://github.com/yanxu-orange/ST-Orange-Yancang-TT-Bridge

扩展显示名为“砚藏联动”。若此前通过ZIP安装过同名桥，请先在TT扩展管理中停用或移除旧桥，再安装本仓库，避免两份桥同时运行；不需要删除角色卡或其他资料。仓库根目录的manifest.json、index.js、style.css、diagnostic.js和本README即完整普通桥。旧Git安装可通过TT扩展管理更新后重载。

已有官方归档ZIP时也可使用TT“扩展→数据迁移→导入数据归档包”安装，仍须避免旧ZIP目录与Git目录同时启用。

## 建立连接

从砚藏“TauriTavern导入”或角色详情发送入口，点击“开始连接”→“复制连接码”→“打开TT”。在“砚藏联动”粘贴并“连接”，返回砚藏继续操作。已有有效连接无需重新配对。

## 发送角色卡到TT

砚藏角色详情“发送至酒馆”→“TauriTavern”，连接后点击“继续发送”并按页面步骤发送；在TT点击“确认接收为新角色”。发送当前查看版本及当前头像，只普通新增，不覆盖同名卡。刷新失败只重试列表刷新，未知业务回执不要重复发送同一任务。

## 从TT导入

砚藏“导入”→“TauriTavern”→“读取角色列表”。目录未就绪时，打开TT等待角色列表读取，再返回砚藏勾选并“导入所选”。完整卡尚未读取完成时，打开TT等待读取，再返回砚藏准备导入预览，点击“确认导入”才入库。

目录读取和完整卡读取是两个阶段；后台已完成时直接继续，不必无意义切换应用。预览仍保留原有重复/版本选择，TT附加字段仅在批准的受限范围内识别为同内容，不按同名强行合并。缩图只用于选择，正式传输保持完整PNG。

## 连接与已知限制

本次最多十分钟，重贴、完成及取消操作均不续期。砚藏会话仍有效时可在TT主动重贴原码；砚藏结束、到期或进程结束后需新码。取消当前操作不等于断开整个连接，用完请断开。

十分钟授权不保证系统持续允许后台执行。首次初始化可能出现红警，手机后台也可能暂时中断；锁定砚藏后台仅为部分情况下的改善方法，不能保证解决。代理开启时此桥停止，不更改全局代理。连接秘密不持久保存；不会自动重连或重放业务。

## 联动诊断

出现问题后，可从砚藏设置的TauriTavern内“导出联动诊断”，以及TT“砚藏联动”的连接同行“导出诊断”分别保存最近记录。断开或重新打开应用后仍可导出；取消保存不会删除记录。“清除记录”只清除本端记录，不结束连接。

普通版也可使用，无需诊断专用包。记录仅包含固定阶段、相对耗时及结果分类，不记录角色卡内容、卡名、连接码、端口或凭证，不自动上传。每端最多1024条/256KiB，采用有限分段与摘要保留，24小时后在下次使用时逻辑过期；导出可能标明截断及持久化不完整。两端相对时钟不能直接相减。砚藏判重摘要只说明有限比较结果，不能保证定位所有差异。
